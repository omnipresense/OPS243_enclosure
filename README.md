# OPS243_enclosure
Design files for enclosure fitting OPS243 including space for battery and charger/converter board.
Design files are provided as .stp files and can be brought in to any 3D printing program.  Make sure to print the top enclosure lid at 100% fill.
Datasheet provides all the mechanical details of the design along with assembly steps and bill of materials including battery and charger/converter board.
Use this design with OPS243 with WiFi interface as USB interface is for battery charging only, no data.
